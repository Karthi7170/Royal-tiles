# New Royal Tiles

Premium, mobile-first multi-showroom website for **New Royal Tiles** in North Tamil Nadu.

## Showrooms represented

- Valayambattu / Vaniyambadi — flagship
- Vellore / Konavattam
- Gudiyatham / Sedukkarai
- Pernambut / Sathkar

The branch data in the site is based on current public business listings and should be rechecked whenever showroom contact details or addresses change.

## Experience included

- Premium espresso, champagne-gold and porcelain-ivory visual system
- Real New Royal Tiles logo and flagship showroom exterior
- Full-image mobile hero treatment that avoids aggressive showroom cropping
- Responsive desktop/mobile navigation
- Room-led collection discovery
- **Browser room visualizer** with:
  - phone camera / image upload
  - floor vs wall preview
  - multiple tile directions
  - preview strength control
  - tile scale control
  - WhatsApp handoff for similar products
- Inspiration gallery
- Tile area + wastage calculator
- Four-showroom branch finder with directions and verified public contact details where available
- Branch-aware WhatsApp quote form
- Catalogue request journey
- Google rating trust section
- Flagship Google Maps embed
- Click-to-call, WhatsApp and directions CTAs
- Multi-location LocalBusiness structured data
- Mobile-first responsive styling
- Reduced-motion accessibility support

## Visualizer positioning

The room visualizer is a browser-based **concept preview**, not spatially tracked WebAR. It is intended to help customers shortlist a tile direction before visiting a showroom. Actual tile shade, joint width, scale, surface texture and gloss should always be confirmed using physical samples.

A true 360-degree virtual showroom or plane-tracked AR experience should only be added after genuine 360 showroom photography and production tile texture assets are available.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production check

```bash
npm run typecheck
npm run build
npm start
```

The project is structured for Vercel deployment from the `main` branch and includes a GitHub Actions build check.

## Before public launch

Replace remaining editorial stock imagery with genuine product displays, tile collections, showroom interiors and completed customer projects. Confirm all four branch addresses and phone numbers with the business owner. After a permanent domain is chosen, add the final canonical URL, Search Console verification, sitemap and website URL to each relevant Google Business Profile.
