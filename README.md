Premium, mobile-first showroom website for **New Royal Tiles**, Valayampattu, Tamil Nadu.

## Experience included

- Premium editorial homepage
- Responsive desktop/mobile navigation
- Room-led tile collection discovery
- WhatsApp recommendations and prefilled enquiries
- Inspiration gallery
- Tile area + wastage calculator
- Google rating trust section
- Embedded Google Maps location
- Click-to-call and directions CTAs
- LocalBusiness structured data for search engines
- Mobile-first responsive styling
- Reduced-motion accessibility support

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production check

```bash
npm run typecheck
npm run build
npm start
```

The project is structured for Vercel deployment from the `main` branch.
